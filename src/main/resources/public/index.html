Control Gimnasio — API Web

El servidor HTTP está en ejecución. Puedes empezar a consumir los endpoints REST:

  • /api/status — Verifica que el backend esté activo.
  • /api/clientes — Devuelve el listado de clientes registrados en SQLite.

Puedes conectar un frontend en HTML/CSS/JS o cualquier cliente HTTP para continuar con la migración.
